# CalcForge

CalcForge is a calculator with trigonometry, logarithms (natural, base10, etc), mathematical constants, absolute values, radicals, exponents, arithmetic operators, step-by-step instructions, angle modes (that are graphed), buttons switching between radians and degrees, exponent associativity, history (check on your past calculations), and more coming soon (graphing & calculus mode)!
